原文题目：Motion Analysis and Control of Three-Wheeled Omnidirectional Mobile Robot

中文题目：三轮全向移动机器人的运动分析与控制

作者：Nacer Hacene，Boubekeur Mendil

原文出处：Journal of Control, Automation and Electrical Systems，2019，30：194-213

摘 要

全向移动机器人是一类完整约束车辆，能够实现平移运动与旋转运动的相互独立及同步执行。本文对三轮全向移动机器人进行了系统而细致的运动学数学分析，并在此基础上建立了该机器人的运动学模型。研究表明，该类机器人的运动可划分为三种基本形式：纯旋转运动、直线平移运动以及绕某一非零半径点的旋转运动。

与此同时，本文还讨论了轨迹跟踪控制问题，即机器人在跟踪期望轨迹的同时，还需实现对期望姿态的跟踪。为解决该问题，文中设计了一种模糊控制器。通过将所提出的控制器与已有文献中的另一种控制方法进行对比，结果表明：仅采用最少模糊规则数目（仅 4 条规则）的模糊控制器，仍表现出更高的控制效率与更优的跟踪精度。

此外，本文提出了一种简单有效的运动学饱和处理方法，其核心在于保证控制输出始终处于允许控制范围之内。最后，基于 MATLAB 构建了仿真平台，以验证所提方法的有效性与可行性。

关键词：三轮全向移动机器人；自主导航；轨迹跟踪；运动学饱和；模糊逻辑

1 引言

近年来，移动机器人受到了越来越广泛的关注，并已在多种环境中得到应用，例如地面环境、空中环境及水下环境。依据运动约束特性，轮式移动机器人通常可划分为完整约束机器人与非完整约束机器人两大类。非完整约束机器人主要包括自行车型机器人、差速驱动机器人、三轮式机器人以及类汽车式机器人等。所谓完整约束机器人，是指其驱动维数与系统自由度数相同的机器人系统。

全向移动机器人属于完整约束机器人，即其能够在平移与旋转两个运动维度上实现彼此独立且同步的运动控制。该类机器人能够在不受车体当前朝向限制的条件下沿任意方向运动，因此在诸多应用场合中具有显著优势。例如，其已广泛应用于个人辅助、康复护理、工业生产、服务机器人以及机器人竞赛等领域。

自 Grabowiecki 于 1919 年发明全向轮以来，研究者相继提出了多种全向轮结构形式，如球形脚轮、麦克纳姆轮、球轮、纵向正交轮、MY 轮、MY wheel-II 以及 ACROBAT 驱动系统等。从本质上讲，这类轮机构在主动驱动方向上能够提供牵引力，而在垂直于主动方向的方向上，则可依靠自由滚动机构实现被动运动。

已有大量研究围绕三轮全向移动机器人（Three-Wheeled Omnidirectional Mobile Robot，TWOMR）的运动学和动力学建模展开，但真正从一般性角度对其运动特性进行深入分析的研究相对较少。Ashmore 与 Barnes 对全向驱动系统的运动进行了分析，首先描述了简单两轮全向轮系统的运动形式，继而推导出 n 轮全向驱动机器人的速度方程。Ribeiro 等人从直线运动、角运动和混合运动三个方面描述了三轮全向移动机器人的运动，但并未进一步建立其系统运动学模型。Barua 等人在建立 TWOMR 运动学之后，考察了三轮速度的若干组合情形，但其分析主要仍限于部分典型工况。Dong 等人利用运动学仿真分析软件对 T 型与等边三角形平台两种模型进行了分析，但仅展示了 T 型模型的结果，并将其归纳为若干特定运动形式。Mohanraj 等人则通过可变角底盘研究了前部两轮夹角变化对机器人前进与后退线速度的影响，其研究对象本质上仍属于特定直线运动情形。

综上可见，现有研究大多仅针对若干常见特殊情形进行分析，例如若干固定方向上的运动、轮子满速运行状态等，而缺乏对三轮全向移动机器人在任意轮速取值条件下运动规律的普遍性分析。此外，这些研究往往未能充分揭示机器人运动特征的细节。例如，对于双轮差速机器人，在给定两驱动轮速度的情况下，通常可以较容易地求得其线速度、角速度、航向角、瞬时曲率中心以及瞬时旋转半径等关键运动参数。

本文旨在弥补上述研究不足，对三轮全向移动机器人在三个轮子速度取任意值、且可沿正反两个方向运动的情况下，开展系统而一般性的运动分析。该分析重点研究各类速度及作用关系，并依据三个轮子输入速度计算出如下运动特征：机器人线速度及其方向、机器人角速度、各轮综合线速度及其方向、瞬时曲率中心坐标以及瞬时旋转半径等；同时，基于几何方法建立 TWOMR 的运动学模型。为直观展示机器人的运动规律及不同速度之间的关系，本文还构建了相应的仿真平台。

在建立运动学模型之后，本文进一步讨论了另一关键问题，即运动学饱和问题。换言之，在控制器生成控制输出时，必须保证车轮速度不超过其最大允许值。由于三轮全向移动机器人可以分别控制平移速度和角速度，因此在控制输出生成过程中极易出现轮速超限问题。现有文献常采用近似方法来处理该问题，但通常会排除部分本可实现的速度解。鉴于此，本文提出了一种简单而直接的饱和处理方法，在不排除任何可行速度的前提下，实现对电机速度的约束。

此外，本文还研究了轨迹跟踪控制问题，并设计了一种模糊控制器，同时将其与文献中的另一种控制方法进行了比较分析。

全文结构安排如下：第 2 节对三轮全向移动机器人的运动进行数学分析；第 3 节提出一种简单的运动学饱和处理方法；第 4 节讨论轨迹跟踪控制问题；第 5 节给出仿真结果；最后总结全文并展望未来研究方向。

2 三轮全向移动机器人运动的数学分析

2.1 机器人描述

三轮全向移动机器人是一种完整约束移动机器人，具备平移与旋转同时且相互独立执行的能力。该机器人装配有三个全向轮，三个车轮均匀分布于机器人圆周上，彼此夹角均为 120°。每个全向轮均直接安装于对应电机轴上，因此电机与车轮具有相同的旋转轴。通过分别控制各电机的转速，机器人便能够实现常规轮式机器人难以实现的复杂运动。

全向轮的典型结构由轮体与大量滚子组成。滚子的存在使车轮除可沿正常滚动方向运动外，还能够在垂直于正常滚动方向的方向上进行侧向运动。一般而言，一个完整的全向驱动系统至少需要配置三个全向轮。

2.2 诱导速度

考虑一个三轮全向驱动系统。设右侧的轮 1 为主动轮，其线速度为 Vw1，而轮 2 与轮 3 处于非主动状态。在无滑移条件下，轮 2 与轮 3 会由于滚子的作用，在垂直于各自正常滚动方向的方向上产生速度分量，该速度称为“诱导速度”。

因此，整个系统将绕某一点 C 发生转动，该点为轮 1 速度方向法线与轮 2、轮 3 诱导速度方向法线的交点。

依据几何关系，在所构造的几何图形中可推导出： R2 = √3L R = 2L R1 = 3L

由于此时机器人绕同一旋转中心运动，因此各点具有相同角速度，有： phi_dot = Vw1 / R1 = Vin1 / R2

进一步可得： Vin1 = Vw1 / √3

推广至一般情形，当轮 j 的驱动线速度为 Vwj 时，其对应的诱导速度满足： Vin_j = Vwj / √3

该诱导速度由其余两个轮子被动获得，对相邻后一个轮子表现为外向速度，对前一个轮子表现为内向速度。由公式可知，Vin_j 与 Vwj 具有相同符号。

2.3 三轮全向机器人运动分析

考虑一般工况，即三个轮子分别施加线速度 Vw1、Vw2 和 Vw3。规定逆时针方向为正旋转方向。在机器人质心处建立局部坐标系（o，xl，yl），其中 xl 轴与轮 1 的转轴方向平行。同时，分别在各轮处建立轮系坐标系（w1，x1，y1）、（w2，x2，y2）和（w3，x3，y3），其中各 xj 轴与对应轮轴方向平行。

轮子的驱动速度 Vwj 均按代数值处理，即若速度方向与正方向一致，则取正值；反之取负值。通过将各轮坐标系中的速度分量变换至机器人局部坐标系，并叠加轮子的主动速度与诱导速度，可以得到各轮综合速度在机器人局部坐标系中的表达形式。

进一步推导后，可得机器人在局部坐标系中的平移速度分量为： Vx = -(√3 / 3)Vw2 + (√3 / 3)Vw3 Vy = (2 / 3)Vw1 - (1 / 3)Vw2 - (1 / 3)Vw3

机器人整体角速度为： phi_dot = (Vw1 + Vw2 + Vw3) / (3L)

由此可建立三轮全向移动机器人的正运动学方程： x_dot = -(√3 / 3)Vw2 + (√3 / 3)Vw3 y_dot = (2 / 3)Vw1 - (1 / 3)Vw2 - (1 / 3)Vw3 phi_dot = (1 / 3L)Vw1 + (1 / 3L)Vw2 + (1 / 3L)Vw3

机器人平移速度大小可表示为： V = √(Vx² + Vy²)

其运动方向为： theta = atan2(Vy，Vx)

其中，atan2 为四象限反正切函数，其取值范围为 [-pi，pi]。

此外，各轮综合平移速度的大小与方向分别为： Vj = √(Vjx² + Vjy²) theta_j = atan2(Vjy，Vjx)

在求得各轮综合速度后，可通过作各综合速度方向的垂线，并使其经过对应车轮中心，从而求得机器人瞬时曲率中心 C（Cx，Cy）。经化简后，瞬时曲率中心坐标可表示为： Cx = L(-2Vw1 + Vw2 + Vw3) / (Vw1 + Vw2 + Vw3) Cy = √3L(-Vw2 + Vw3) / (Vw1 + Vw2 + Vw3)

机器人瞬时旋转半径为： R = √(Cx² + Cy²)

而机器人平移速度与角速度亦可进一步表示为： V = (1 / 3)√[(-Vw2 + Vw3)² + (2Vw1 - Vw2 - Vw3)²] phi_dot = (Vw1 + Vw2 + Vw3) / (3L)

基于上述推导结果，三轮全向移动机器人的运动可概括为以下三种类型。

第一，当 Vw1 + Vw2 + Vw3 = 0 时，phi_dot = 0 且 V ≠ 0，机器人作瞬时纯平移运动。

第二，当 Vw1 = Vw2 = Vw3 时，V = 0 且 phi_dot ≠ 0，机器人作瞬时纯旋转运动。

第三，若上述两个条件均不满足，则机器人沿瞬时圆轨迹运动，其平移速度为 V，旋转半径为 R。

其中，第一种情况对应于旋转半径趋于无穷大的圆周运动，即纯平移；第二种情况对应于旋转半径为零的情况，即绕自身中心纯旋转；第三种情况则对应于绕某一非零半径点的圆周运动。

3 运动学饱和

为了设计具有良好控制性能的控制器，必须保证机器人平移速度与角速度始终处于执行机构允许的范围内。对于三轮全向移动机器人而言，若通过逆运动学将机器人期望的平移速度和角速度映射为各车轮速度，则必须进一步确保所得轮速不超过车轮的最大允许转速。

文中指出，在轮速空间中，允许的轮速范围可表示为一个立方体；而经正运动学映射到机器人局部速度空间后，该可行域将表现为一个倒置的平行六面体。换言之，机器人局部速度空间中的可行控制输出并不易通过简单解析公式直接表达，因此精确求解其边界通常较为复杂。

现有文献中，多数方法采用近似处理方式，例如利用“速度锥”对可行速度域进行近似，仅保留锥体内部速度，而将锥体外部的速度全部舍弃。这种方法虽然简化了计算，但同时也排除了部分本可实现的速度解。

针对上述不足，本文提出了一种简便而有效的方法来确定满足约束的轮速输出。该方法不排除任何可能的可行速度，也无需对复杂可行域进行繁琐求解。其基本思路如下。

首先规划角速度 phi_dot ∈ [-phi_dot_max，phi_dot_max]，随后规划指向目标方向的平移速度 V。将该平移速度投影到机器人局部坐标系 xl 和 yl 方向后，可得到 x_dotl、y_dotl 与 phi_dotl。再通过逆运动学求得理论轮速向量： Vw_hat = [Vw1_hat，Vw2_hat，Vw3_hat]^T

由于该理论轮速可能超出允许范围，因此需进行限幅处理。

设车轮最大线速度为 Vw_max，则任一轮速均应满足： -Vw_max ≤ Vwi ≤ Vw_max

令三个理论轮速绝对值中的最大值为： M = max(|Vw1_hat|，|Vw2_hat|，|Vw3_hat|)

则最终输出轮速满足： 若 M ≤ Vw_max，则直接采用理论轮速； 若 M > Vw_max，则对三个轮速按同一比例进行缩放，使其最大绝对值恰好等于 Vw_max。

该方法具有实现简单、计算量小、保留全部可行速度解等优点，因而具有良好的工程实用价值。

4 轨迹跟踪控制

轨迹跟踪问题要求机器人在运动过程中不仅能够跟踪期望位置轨迹，还需同时跟踪期望姿态。由于三轮全向移动机器人具备同步平移与旋转的能力，因此本文采用如下控制策略：施加一个指向目标点的平移速度 V 以减小位置误差，同时施加一个角速度 phi_dot 以减小姿态误差。

机器人与目标点之间的距离误差定义为： Dis = √[(xd - xG)² + (yd - yG)²]

姿态误差定义为： Delta phi = phid - phi

其中，（xd，yd）为期望位置，（xG，yG）为机器人当前位置，phid 为期望姿态，phi 为机器人当前姿态。

整体控制系统中，控制器的输入为： Delta x = xd - xG Delta y = yd - yG 以及姿态误差 Delta phi。

控制器最终输出为三个车轮的线速度 Vw1、Vw2 和 Vw3。

从结构上看，该控制器主要由三个模块构成。

第一，内部控制器模块。其输入为距离误差 Dis 与姿态误差 Delta phi，输出为机器人期望平移速度 V 和角速度 phi_dotl。该内部控制器可采用 PID、神经网络或模糊控制器等形式，本文采用模糊控制器。

第二，逆运动学模块。其输入为 x_dotl、y_dotl 与 phi_dotl，其中： x_dotl = Vcos(beta) y_dotl = Vsin(beta) 这里 beta = atan2(Delta y，Delta x)，表示目标点相对于机器人当前位置的方位角。

第三，饱和处理模块。由于逆运动学输出的理论轮速不一定满足车轮最大速度约束，因此需通过前述饱和方法对其进行限幅。

4.1 模糊控制器

模糊逻辑系统的理论基础来源于人类基于感知信息进行推理和决策的能力。基于规则的模糊逻辑为不确定及不精确信息条件下的控制问题提供了一种有效的形式化方法。模糊控制器本质上是输入与输出之间的一种静态非线性映射，其输入和输出均为精确数值，而非模糊集合本身。

一个典型模糊控制器主要由四部分组成：模糊化模块、规则库、推理机制和去模糊化模块。模糊化模块用于将精确输入映射为相应的模糊集合；规则库存储关于如何控制系统的知识与规则；推理机制根据当前输入判断哪些规则被激活，并由此生成模糊结论；去模糊化模块则将模糊推理结果转换为精确输出。

本文设计的模糊控制器包含两个输入量，即机器人与目标位置之间的距离 Dis 以及机器人姿态与目标姿态之间的误差 Delta phi；对应两个输出量，即平移速度 V 与角速度 phi_dot。

4.2 模糊化过程

在模糊化过程中，本文对不同变量采用了不同形式的隶属函数。其中，输入变量 Dis、Delta phi 以及输出变量 phi_dot 采用三角形与梯形隶属函数；输出变量 V 则采用高斯隶属函数。

各变量的语言变量取值如下： 对于 Dis：零（Z）、远（F）； 对于 V：零（Z）、大（B）； 对于 Delta phi 与 phi_dot：负（N）、零（Z）、正（P）。

4.3 规则库设计

本文所设计模糊控制器的规则库仅包含 4 条规则。

规则 1：当 Dis 为零且 Delta phi 为负时，输出 V 为零，phi_dot 为零。 规则 2：当 Dis 为远且 Delta phi 为负时，输出 V 为大，phi_dot 为负。 规则 3：当 Dis 为远且 Delta phi 为零时，输出 V 为大，phi_dot 为零。 规则 4：当 Dis 为远且 Delta phi 为正时，输出 V 为大，phi_dot 为正。

由此可见，本文所提控制器在规则数量极少的条件下实现了对机器人平移与姿态控制的统一协调。

4.4 去模糊化过程

本文采用重心法进行去模糊化处理。该方法通过求取输出模糊集合曲线下方面积的几何中心位置，获得最终的精确控制输出。由于其物理意义明确、实现方便，因此在模糊控制中应用十分广泛。

5 仿真结果

本文采用 MATLAB 对所提出的方法进行了仿真验证。仿真内容首先包括对机器人运动分析结果的验证，随后通过点稳定控制与轨迹跟踪控制两个典型实验，对所提方法的控制性能进行测试，并与 Wang 等人提出的方法进行对比。为保证对比的公平性，本文采用与 Wang 等人相同的实验条件和系统参数，其中车轮最大线速度取 2 m/s。此外，文中还给出了若干复杂场景下的仿真结果，以进一步验证所提方法的适用性。

5.1 运动分析仿真

机器人运动分析仿真主要包括以下三种典型工况：绕自身质心纯旋转、纯平移运动以及绕任意点 C 且半径为 R 的旋转运动。

为便于图示分析，文中采用不同颜色分别表示不同速度类型：车轮驱动速度 Vwj 以红色表示，诱导速度 Vin_j 以蓝色表示，各轮综合平移速度 Vj 以黑色表示，机器人中心平移速度 V 以黄色表示，而旋转中心 C 以红色点状圆圈表示。

5.1.1 纯旋转

当三个车轮沿同一方向、以相同速度驱动时，即满足： Vw1 = Vw2 = Vw3

机器人将绕其质心进行纯旋转。文中所给示例中： Vw1 = Vw2 = Vw3 = 0.5 m/s

5.1.2 纯平移

当三个轮速的代数和为零时，即： Vw1 + Vw2 + Vw3 = 0

机器人作纯平移运动。仿真示例中，车轮速度取值为： Vw1 = 1，Vw2 = -0.7，Vw3 = -0.3

5.1.3 绕点 C、半径为 R 的旋转

若上述两个条件均不满足，则机器人将绕某一异于自身中心的点 C 进行旋转运动，且旋转半径满足 R ≠ 0。

5.2 点稳定控制

点稳定控制是指机器人从初始位置出发，到达某一固定目标点并最终稳定于该点，其过程类似于控制系统的阶跃响应。文中将所提方法与 Wang 等人的方法在相同工况下进行比较。

在该实验中，机器人初始位姿设定为（0 m，0 m，0 rad），目标位姿设定为（3 m，2 m，pi/3）。

仿真结果表明，相较于 Wang 等人的方法，本文所提出的方法能够使机器人沿起点至目标点之间的最短路径，即近似直线轨迹，迅速到达目标；而 Wang 等人的方法虽然也能实现目标到达，但其路径相较期望轨迹存在明显偏差。

从坐标响应曲线可以看出，本文方法的响应时间约为 2.23 s，而 Wang 等人方法的响应时间约为 5 s。姿态响应结果进一步表明，本文方法不仅响应更快，而且精度更高，且响应过程无明显振荡现象。

从轮速曲线来看，在运动初始阶段，三个车轮均接近以最大速度 2 m/s 转动，此时机器人主要通过逆时针旋转快速跟踪目标姿态 pi/3；随后机器人进入直线运动阶段并朝目标点前进。当三个轮速之和为零时，对应于机器人纯平移运动状态。在约 2.23 s 时，机器人到达目标并保持稳定，而 Wang 等人的方法则约需 5 s 才能到达目标。

从跟踪误差结果可知，本文方法的最大跟踪误差小于 1 mm，而 Wang 等人方法的最大误差约为 4 cm。由此可见，本文方法在点稳定控制中具有更高的精度与更优的动态性能。

5.3 轨迹跟踪

在该实验中，机器人需要跟踪一条脉冲型轨迹。该轨迹由 6 个节点构成，各节点位姿参数如下：

节点 1：（0，1，0） 节点 2：（2，1，0） 节点 3：（2，3，pi/2） 节点 4：（4，3，0） 节点 5：（4，1，-pi/2） 节点 6：（6，1，0）

仿真结果显示，在本文方法作用下，机器人能够在相邻节点之间沿最短路径，即两节点之间的直线进行运动，基本不偏离期望轨迹；而 Wang 等人的方法则存在较明显的轨迹偏离。

在姿态跟踪方面，本文方法也表现出更好的性能。结果表明，在相邻节点之间，机器人通常仅需约 0.13 s 即可达到期望姿态，这意味着机器人在节点间绝大部分运动时间内均能够保持正确姿态。相比之下，Wang 等人的方法几乎需要耗费整个节点间运动时间来完成姿态调整，因此仅能在较短时间内保持目标姿态。

从线速度和角速度曲线还可看出，本文方法完成整条轨迹所需时间约为 6.37 s，而 Wang 等人的方法完成同一轨迹约需 30 s。此外，本文方法能够更快完成姿态调整，并在整个运动过程中保持较高的姿态跟踪质量。

轨迹误差结果表明，本文方法的最大轨迹跟踪误差小于 1 cm，而 Wang 等人方法的最大误差约为 8 cm。点稳定控制与轨迹跟踪两个实验的结果共同说明：相较于文献中所采用的方法，本文所提出的方法在控制速度与跟踪精度方面均具有明显优势。

5.4 复杂场景

为了进一步验证所提方法的适用性与灵活性，文中还设计了若干复杂轨迹仿真场景。结果显示，机器人均能够成功实现轨迹与姿态的同步跟踪。

在第一种复杂场景中，机器人需要跟踪圆形轨迹，同时姿态还需跟踪一个幅值与时间尺度均发生变化的振荡信号。

在第二种复杂场景中，机器人需要跟踪网格状轨迹，并始终保持姿态角为零。

在第三种复杂场景中，机器人跟踪花形轨迹，同时姿态按照正弦规律变化。

在第四种复杂场景中，机器人成功跟踪了类似蜻蜓形状的复杂轨迹，同时姿态跟踪一个幅值变化的振荡信号。

上述复杂工况仿真结果进一步验证了所提控制方法在复杂运动任务中的有效性与较强适应能力。

6 结论

本文对三轮全向移动机器人的运动进行了较为系统和深入的数学分析，并据此建立了其运动学模型。研究结果表明，三轮全向移动机器人的运动形式可划分为三类：绕机器人中心的纯旋转运动、纯平移运动以及绕不同于机器人中心的某一非零半径点的旋转运动。

针对轨迹跟踪控制问题，本文设计了一种模糊控制器，使机器人能够在跟踪期望轨迹的同时实现对期望姿态的有效跟踪。通过大量仿真实验验证了该方法在三轮全向移动机器人轨迹跟踪问题中的有效性、灵活性和优越性。

通过与已有文献中的另一种控制方法进行比较可以发现，本文所提出的模糊控制器虽然仅采用了 4 条模糊规则，但其控制效果却优于模型预测控制方法。这在一定程度上说明，在某些工程控制问题中，结构简单的方法同样可能获得更优的效果。

此外，所有电机速度始终被限制在允许控制范围之内，验证了本文所提出运动学饱和处理方法的有效性。未来的研究工作将进一步拓展至多机器人系统。
